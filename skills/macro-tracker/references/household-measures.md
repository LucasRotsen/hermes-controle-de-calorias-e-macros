# Household measures → grams (Brazil)

Typical edible weights for common Brazilian measures, as a starting point when the user gives no grams.
They vary with the cook, the utensil and the brand. When a meal matters or repeats, ask the user to weigh
it once and save it as a shortcut or custom food. Tell the user which grams you assumed.
